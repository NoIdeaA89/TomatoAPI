Este proyecto utiliza **Docker Compose** para orquestar la base de datos (PostgreSQL) y el backend (FastAPI) de forma automática. No necesitas instalar dependencias de Python ni configurar bases de datos localmente.

### 📋 Requisitos Previos
* Tener instalado [Docker Desktop](https://www.docker.com/products/docker-desktop).
* Asegurarte de que el motor de Docker esté corriendo.

### 🛠️ Pasos para levantar el Backend y la Base de Datos

1. Abre una terminal y navega hasta la carpeta raíz del proyecto (`TomatoAPI`).
2. Ejecuta el siguiente comando:
   ```bash
   docker compose up


luego para levantar frontend
npm run dev
